## Workout log

> Work in progress

Local webapp for logging workouts.

Made for learning purposes.
Hand-written, using Claude as a learning aid to
understand Vue and .NET concepts.

### Stack

- Backend: .NET / C#, ASP.NET Core, Entity Framework Core, SQLite
- Frontend: Vue 3, Vuetify

### Running locally

Backend:

```bash
cd backend
dotnet run
```

Frontend:

```bash
cd frontend
npm install
npm run dev
```
